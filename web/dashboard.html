Aegis AI

The Autonomous Chief Risk Officer for Bitget — governs Bitget GetAgent Playbooks instead of generating new signals.

Bitget AI Hackathon S1 · Trading Agent Track

Thesis

Problem: signal generation is commoditized — the real failure mode in automated trading is no systematic governance over when to trade, how much, and when to stop.

Solution: Aegis sits above existing Bitget Playbooks, reading all 5 Agent Hub skills to classify market regime, then governs capital and leverage rather than picking trades itself.

Edge: on identical market paths, Aegis-governed execution achieves a far better risk-adjusted profile than the same Playbooks run ungoverned — see the comparison below.

Proof of Value — Governed vs. Ungoverned

Same simulated 80-tick market path, same starting balance. The ungoverned baseline trades every regime at full size with no pause logic. Aegis accepts a lower raw return in exchange for a ~3.5x better return-to-drawdown ratio — survival first, then return.

Architecture

Agent Hub Skills (macro, market-intel, sentiment, technical, news)
        │
        ▼
Regime Detection  (BULLISH / BEARISH / CHOPPY / TRANSITIONING)
        │
        ▼
Chief Risk Officer  (TRADE / REDUCE / PAUSE + risk budget + leverage cap)
        │
        ▼
Playbook Selection & Activation  (permitted Bitget GetAgent Playbooks)
        │
        ▼
Risk Allocation & Position Sizing  (volatility-scaled SL/TP)
        │
        ▼
Paper Trading Execution  →  Trade Logger (CSV)  →  Feedback Loop
